# Repository Instructions

## Project Overview

This repository contains the Agentic Customer Ownership Copilot, a proof-of-concept automotive customer assistance platform.

The system combines:
- Retrieval Augmented Generation (RAG)
- Predictive maintenance experimentation
- Service recommendation logic
- Escalation handling
- Tool orchestration

## Development Rules

- Understand existing code before modifying it.
- Make small, focused changes.
- Do not create unnecessary files or folders.
- Do not rewrite working code without a clear reason.
- Preserve existing architecture decisions.
- Prefer simple, explainable solutions over unnecessary complexity.

## Code Quality

- Use clear variable and function names.
- Add type hints to important Python functions.
- Keep functions small and focused.
- Add comments only where they explain reasoning.
- Avoid duplicated logic.

## Testing

Before considering a task complete:

- Run relevant tests.
- Explain what was tested.
- Do not claim success without verification.

## Git Rules

- Do not make large unrelated changes.
- Do not modify Git history.
- Do not use destructive commands.
- Suggest meaningful commit messages.

## Security

Never:
- Commit API keys.
- Read or expose secrets.
- Add credentials to source code.
- Store .env files in Git.

## Project Constraints

- Use synthetic or publicly usable data only.
- Do not use proprietary company information.
- Keep the project understandable for interview explanation.
- Prefer MVP completion over unnecessary features.
